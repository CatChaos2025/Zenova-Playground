# 🎮 Zenova Playground

![Zenova Preview](https://images.unsplash.com/photo-1550745165-9bc0b252726f?auto=format&fit=crop&w=1200&q=80)

Bienvenido a **Zenova Playground**, la plataforma definitiva de juegos web con una interfaz de usuario ultra moderna e interactiva. Inspirado en las líneas fluidas de *Material You*, este proyecto no es solo un catálogo de juegos, es un entorno inmersivo que simula la experiencia táctil y dinámica de un sistema operativo futurista directamente en tu navegador.

## ✨ Características Principales

* **Arcade Dinámico:** Navega por nuestra colección de juegos web en un entorno fluido y sin interrupciones.
* **Diseño Material You:** Tarjetas redondeadas, colores adaptativos centrados en un vibrante tono morado y sombras suaves.
* **Interactividad OS-Like:** Ventanas flotantes para los juegos, animaciones de entrada/salida y estado persistente.
* **Rendimiento Extremo:** Transiciones de estado sin recargas para que la acción nunca se detenga.

## 🛠️ Tecnologías Usadas
